# Desenvolvimento de Interfaces

Repositório com os exercícios práticos desenvolvidos na disciplina de Desenvolvimento de Interfaces, focados em lógica de programação com JavaScript e estruturação com HTML5.

## 📌 Aulas

* **Aula 1:** Calculadora simples no console.
* **Aula 2:** Classificador de resultados com condicionais e repetição.
* **Aula 3:** Aplicação web interativa com formulário e eventos.

## 🛠️ Tecnologias e Ferramentas

* **Linguagens:** HTML5 e JavaScript
* **Editor:** Visual Studio Code (VS Code)
* **Ambiente de Execução:** Google Chrome
